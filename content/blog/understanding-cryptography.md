## Important Terms and Their Meanings

1. **Key:** Used to lock and unlock data using either a random string of bits or a custom string of bits.
2. **Bits:** A logical state with one of two possible values, including `1`/`0`, `true`/`false`, `yes`/`no`, or `on`/`off`.
3. **Hash function:** An algorithm that generates a fixed-size output from an input.
4. **Hash:** The output of a hash function.
5. **Cipher:** An algorithm used to encrypt and decrypt information.
6. **Ciphertext:** Scrambled or unreadable text generated by applying a cryptographic algorithm to readable text. It is the output of a cipher.
7. **Stream:** A sequence of bits.

## Cryptography

Cryptography is a technique for enabling secure communication between two systems using various algorithms.

## Importance of Cryptography

- Privacy and confidentiality
- Authentication
- Prevention of cyberattacks

## Types of Cryptography

![Cover Image](/cryptography_types.png)

### 1. Symmetric-Key Cryptography

Symmetric-key cryptography, also known as private-key cryptography, uses the same key for both encryption and decryption. Each user must have access to the same private key. Private keys may be shared through a previously established secure communication channel.

#### Types of Symmetric-Key Algorithms

##### Stream Cipher

A stream cipher encrypts data bit by bit or byte by byte using a keystream generated from a key. It produces ciphertext by combining each bit or byte of readable plaintext with the keystream, usually using XOR.

Stream ciphers are commonly used to encrypt real-time data, such as audio and video calls. Examples include Rivest Cipher 4 (RC4), Salsa20, ChaCha20, Trivium, Grain, CryptMT, and Fibonacci Shrinking.

##### Block Cipher

A block cipher encrypts data in fixed-length blocks. It divides plaintext into blocks and encrypts each block using a mode of operation. Padding may be added when the final block is not full.

Block ciphers are commonly used for file storage and SSL/TLS. Examples include AES and DES.

### 2. Asymmetric-Key Cryptography

Asymmetric-key cryptography uses a pair of keys: a secret key and a public key. For this reason, these algorithms are also called public-key algorithms.

Public-key cryptography is considered more secure than symmetric encryption in some use cases because, although one key is publicly available, an encrypted message can only be decrypted with the intended recipient's private key.

Asymmetric algorithms are used in digital identity systems and digital signatures, such as those used with APK and PDF files. Common examples include RSA (Rivest–Shamir–Adleman) and elliptic-curve cryptography (ECC).

### 3. Hashing

Hashing produces a fixed-length output string from a variable-length input string. The input serves as the plaintext, and the output is the hash.

Hash algorithms are useful in cryptographic systems because they transform data without requiring a separate decryption key. Once plaintext has been hashed, it cannot be decrypted, making hashing a one-way process.

Common hashing algorithms include MD5 and SHA.
